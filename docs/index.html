02 — Что такое DLP Definition
Определение

Дано g, h, найти x

gx ≡ h (mod p)

В конечной циклической группе порядка n возведение в степень — быстрая операция. Обратная — поиск показателя x — вычислительно трудна.

Где применяется
  • Diffie-Hellman — выработка общего ключа.
  • ElGamal — асимметричное шифрование.
  • DSA / ECDSA / EdDSA — электронная подпись.
  • Schnorr — компактные подписи и доказательства.

Асимметрия «легко вперёд, трудно назад» — фундамент криптографии открытого ключа.

SageMath

Универсальность без оптимизаций

Реализует универсальные алгоритмы DLP, но ориентирована на охват, а не производительность. Специализированных оптимизаций нет.

CADO-NFS

Один алгоритм, один кластер

Высокопроизводительная реализация NFS, но охватывает единственный алгоритм и требует кластерных вычислений.

Разработанный модуль занимает нишу между ними: несколько алгоритмов на одной платформе с произвольной точностью — для исследований и обучения.

08 — Алгоритм BSGS Algorithm 01
Алгоритм 01 / Шэнкс

Большие
и малые шаги

Размен времени на память. Множество показателей разбивается на блоки размером порядка sqrt(n). Малые шаги — в хэш-таблице. Гигантские — поиск коллизии за O(1).

Свойства
  • Детерминированный — гарантия нахождения решения.
  • Время O(sqrt(n)), память O(sqrt(n)).
  • Реализация: HashMap + двойной проход.

11 — Эксперимент Results
Параметры теста

7x ≡ y (mod 1 073 741 827)

Простое p ≈ 230, эталонный x = 987 654 321. Все три алгоритма запускаются на одном входе и возвращают совпадающий x.

Замеры и наблюдения
  • BSGS и Поллард ρ — O(sqrt(p)) = 2b/2, экспоненциально по битам.
  • Index Calculus — субэкспоненциально по битам, всё сильнее опережает универсальные методы.
  • Корректность сверена с реализацией полного перебора.

При b = log2 p = 2048: универсальные методы — 21024, Index Calculus — ≈ 2140.
